A turn is your message plus every tool call and subagent run it started.

    Sessions
    How Claude Code tokens are billed

    Each message re-sends your whole conversation. Prompt caching keeps that affordable: earlier context is written to a cache once, then read back cheaply on every later turn.

    Input
    Your new message and fresh context, at the full input price.
    Cache writes
    Saving context for reuse: 1.25x input for a 5-minute cache, 2x for the 1-hour cache Claude Code mostly uses.
    Cache reads
    Reusing saved context, 10x to 40x cheaper than input depending on the model. Usually most of your tokens.
    Output
    What Claude writes. The highest price per token, but the smallest share.

    Use /clear when you switch tasks so later turns stop re-reading context you no longer need.
